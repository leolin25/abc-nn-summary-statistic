========================================================================
WARWICK HPC (AVON) - NEURAL NETWORK RETRAINING & WORKFLOW GUIDE

1. CONNECT TO AVON
------------------------------------------------------------------------
ssh stunfw@avon.scrtp.warwick.ac.uk
(Never run Python training directly on login03; always use sbatch.)


2. PULL UPDATED CODE FROM GITHUB
------------------------------------------------------------------------
cd ~/abc-nn-summary-statistic
git pull

* If git pull reports local conflicts (e.g., from requirements.txt or
  forward_inference.py edits) and you want GitHub's exact version:
  git fetch --all && git reset --hard origin/main

* Remember: If forward_inference.py was overwritten by git pull, ensure
  cuDNN is disabled at line 1 so Avon's Quadro RTX 6000 driver works:
  sed -i '1i import torch; torch.backends.cudnn.enabled = False' DataConditionalABC-main/datacondabc/experiments/schlogl/forward_inference.py


3. UPDATE PYTHON PACKAGES (ONLY IF REQUIREMENTS CHANGED)
------------------------------------------------------------------------
Your working venv is already built with Python 3.12 + PyTorch cu121.
To activate it and install any new package:

source ~/abc-nn-summary-statistic/venv/bin/activate
pip install <package-name>

* IMPORTANT: Do NOT run "pip install -r requirements.txt" directly if
  exported from Windows—it will overwrite PyTorch with an incompatible
  CUDA 13 build and break GPU detection. Always keep torch+cu121:
  pip install torch --index-url https://download.pytorch.org/whl/cu121


4. SUBMIT A RETRAINING JOB (SLURM)
------------------------------------------------------------------------
Navigate to the experiment folder (make sure obs_data.npy is in ~/ if
project_root resolves to /gpfs/home/stats/stunfw):

cd ~/abc-nn-summary-statistic/DataConditionalABC-main/datacondabc/experiments/schlogl
sbatch train.slurm

* Current train.slurm settings:
  - Partition : gpu (max 48h walltime; use gpu-devel for <1h tests)
  - GPU       : --gres=gpu:quadro_rtx_6000:1
  - Script    : python -u forward_inference.py


5. MONITOR & MANAGE RUNNING JOBS
------------------------------------------------------------------------
* Check queue status (PD = Pending, R = Running):
  squeue -u stunfw

* Watch live training output (Ctrl+C exits log view without stopping job):
  tail -f slurm-<JOB_ID>.out

* Check live GPU usage on the assigned compute node:
  srun --jobid=<JOB_ID> --overlap nvidia-smi

* Cancel a running or pending job:
  scancel <JOB_ID>

* Check final status and runtime after job finishes:
  sacct -j <JOB_ID> --format=JobID,JobName,State,Elapsed,ExitCode


6. DOWNLOAD RESULTS TO WINDOWS PC (RUN IN LOCAL POWERSHELL / CMD)
------------------------------------------------------------------------
Run this on your Windows machine (not inside Avon SSH):

scp -r stunfw@avon.scrtp.warwick.ac.uk:~/abc-nn-summary-statistic/DataConditionalABC-main/datacondabc/experiments/schlogl C:\Users\leoli\Downloads\

(Also check ~/lightning_logs on Avon if outputs were saved to ~/)
EOF
